# Testing Plan

## Objective
Validate the controls in the Secure Research Collaboration Workspace to ensure they are effective without being overly burdensome to researchers.

## Methodology
Testing with 3–5 real students.

## Scenarios
1. **Normal Collaboration**:
   - Co-edit a document using ONLYOFFICE.
   - Comment on the document.
   - Attempt an external share.
2. **Departing Student**:
   - Simulate a student departing.
   - Run the exit protocol live.
   - Verify access revocation and ownership transfer.

## Feedback Collection
Record and report honestly what annoyed testers or made them want to work around a control. This is treated as useful evidence, not a failure to hide.
